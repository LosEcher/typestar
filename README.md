# 键帽森林

可爱的中英文打字练习小游戏。无需安装依赖，用浏览器打开 `index.html` 即可游玩，也可运行 `python3 -m http.server 8000` 后访问 http://localhost:8000。

点击词语卡片后输入；中文请使用系统中文输入法。支持中英混合、中文和英文，三个难度分别提供 75、60、45 秒练习时间；提供准确率、每分钟正确字符数、连击、音效和即时反馈。音效由 Web Audio 合成，不加载音频文件。字体无法联网时自动使用本地字体。

当前视觉使用 CSS 绘制，适合轻量单页运行。

模拟键盘中，薄荷色表示英文目标的下一个字母键，珊瑚色表示实际按下的物理键（按键提示为只读展示）。中文目标不推断拼音键位，以兼容拼音、五笔等不同输入法。输入状态依据 composition/input 事件检测，浏览器无法读取系统输入法当前是否处于中英文模式；状态会区分待检测、组词中、中文提交和英文直接输入，并提示 Caps Lock。点击词语卡片可重新聚焦。

输入事件回归检查：`node --test tests/input.test.cjs`。覆盖中文组词期间不计分、提交后不重复计分，以及英文输入状态和目标键提示；真实系统输入法仍需浏览器手工验证。

窗口适配：桌面使用窗口宽高展开，常见桌面尺寸一屏展示游戏、键盘和设置；手机使用可滚动单栏，提供可见的 16px 输入框和至少 44px 的设置按钮。右上角支持进入/退出浏览器全屏，不支持 Fullscreen API 的浏览器隐藏该按钮。页面允许滚动，保留系统软键盘展开时访问内容的能力。

本地开发布局检查记录在（不随公开仓库发布）`tests/artifacts/layout-results.json`，涵盖 1440×900、1920×1080、1024×768、390×844、320×568、844×390 的 Chromium 模拟尺寸。检查通过的全屏进入/退出、390px 输入聚焦与输入计分见 `tests/artifacts/verification.md`。手机模拟不能替代 iOS/Android 真机软键盘、输入法验证。

中文输入提示：可勾选“显示拼音与全拼键位提示”，显示当前汉字的带声调拼音、已完成字符数，以及基于 compositionupdate 的全拼前缀进度和下一参考键。词库中的中文都配有人工标注拼音。全拼只是教学参考；简拼、双拼、五笔和候选字事件不会因不匹配全拼而扣分，正式计分仍校验提交的汉字。组词期间不计分；空格仅提示选词，网页不拦截输入法候选操作。

字符提交后立即给出颜色和音效反馈。一次提交多个字符按 160ms 间隔处理，整词完成停留 480ms 再换词。期间的新输入排队，不直接丢弃；重开和切换模式清空待处理输入。关闭音效时仍保留画面反馈，系统减少动效设置仍生效。

## 词汇范围与错题复习

在“我的练习计划”中选择森林词库、小学示例、中学示例或自己的词汇表。示例词库不对应特定教材版本。语言选择会进一步过滤该范围；当前语言没有词汇时显示空状态，不替换成其他词库。

自定义词表可直接粘贴或导入 UTF-8 TXT：每行一个词，也支持中英文逗号、分号分隔；自动去重。仅支持汉字或英文字母，每词最多 24 字符，每份最多 500 词。导入后需点击“保存并练习”。内置范围提供拼音标注；自定义词没有拼音资料时仍正常校验汉字，不猜读音。

错题本记录输错时的目标词、错误次数、最近错输字符和下次复习时间。一次词语练习中即使纠正完成，只要发生过错误就不提升复习阶段。重新无错完成整词后，依次安排 1、3、7、14、30 天后的复习，之后保持 30 天；再次答错则回到 10 分钟后。“反复练错词”可提前反复练全部错词；“到期复习”每轮依次练启动时已到期的词，每词一遍，完成后停止。

词表和错题保存在当前浏览器的 localStorage，不上传服务器。页面打开、回到前台和每分钟检查到期数量；页面关闭时没有后台通知。浏览器存储不可用时会提示本次临时保存。更换浏览器、设备或页面来源不会自动同步，建议始终使用同一个入口。

Windows 解压后双击 `start-game.cmd` 或 `index.html`。测试运行：`node --test tests/*.test.cjs`。无需 Node.js 也能直接玩游戏，Node.js 仅用于开发测试。

公开验证摘要见 [docs/verification.md](docs/verification.md)。`tests/artifacts/` 为开发机本地证据目录，不包含在公开仓库或交付包中。
